## 本文

※この記事で紹介している診断サイトには、楽天アフィリエイトのリンクが含まれています（PR）。

ITパスポートの勉強を始めようとして、本屋や通販サイトで参考書を探したことはありますか。

「いちばんやさしい」「みんなが欲しかった」「ひとつひとつわかりやすく」「出るとこだけ」……。
どの本の表紙にも「わかりやすい」「一発合格」と書いてあって、結局どれを選べばいいのかわからない。

先日、まわりから実際にこんな声を聞きました。

> 参考書がたくさんありすぎてよくわからない。イエス・ノーで答えて、自分の好みの参考書を探せるサイトが欲しい。

たしかに、そういう場所はあまりありません。
そこで、**YES/NOの10問に答えるだけで、自分に合うITパスポートの参考書がわかる診断サイト**を作りました。

👉 **ITパスポート参考書診断**
https://kenu2004.github.io/sankousho/

登録は不要で、1分ほどで終わります。

### 参考書選びで迷う、3つの理由

作る前に「なぜ選べないのか」を考えてみると、理由は大きく3つありました。

**1. どの本も「わかりやすい」と書いてある**
売れている参考書は、どれも工夫されていて、実際にわかりやすく作られています。だからこそ、宣伝文句だけでは差がわかりません。

**2. 本の良し悪しより「相性」の問題が大きい**
図解が多い本が合う人もいれば、文字でじっくり読みたい人もいます。まず問題を解いてから覚えたい人もいれば、教科書を最初から順番に読みたい人もいます。
「評判のいい本」が、自分にとって「続けられる本」とは限りません。

**3. 自分の勉強のクセを、意外と知らない**
「本と動画、どっちが頭に入る？」「勉強できるのは、まとまった時間？すきま時間？」
こうした質問に、ふだんから答えを持っている人は少ないと思います。

### 診断では「勉強のクセ」を10問で聞きます

診断の質問は、たとえばこんな内容です。

- ITの仕事や勉強をしたことがある？
- 試験日まで1か月を切っている？
- 文字がぎっしりの本は苦手？
- 本を読むより、動画を見るほうが頭に入る？
- 説明を読むより、まず問題を解いてみたい？
- 勉強は通勤・休み時間など、細切れの時間になりそう？

答えに合わせて、9つのタイプのどれかに分かれます。

| タイプ | ひとこと |
|---|---|
| ゼロからていねい型 | 基礎の基礎から、1冊でじっくり |
| 読むだけでイメージ型 | カラー図解で、読みながら覚える |
| マンガで楽しく型 | 物語で読めば、用語が頭に残る |
| すきま時間コツコツ型 | 1テーマずつ、細切れでも前に進む |
| 動画で聞いて覚える型 | 解説を「聞いて」理解する |
| 問題から解く型 | まず解く。わからなければそこで覚える |
| 短期集中・速習型 | 時間がないなら、出るところから |
| 全部おさえる網羅型 | 範囲を漏れなく、しっかり理解 |
| 過去問で仕上げ型 | 経験を活かして、問題演習から |

結果ページでは、タイプごとに **「主役の一冊」と「仕上げの一冊」** の2冊をおすすめしています。

### 「2冊まで」にしている理由

参考書選びで迷う人ほど、不安になって3冊、4冊と買い足してしまいがちです。
でも、どの本も途中までしか進まないのがいちばんもったいない。

なので診断では、

- **主役の一冊**：これを1周する
- **仕上げの一冊**：主役を読み終えたら、問題演習や弱点の確認に使う

という2冊に絞っています。

### おすすめしている本について

- 2026年度の試験向けに出ている参考書から選んでいます
- 本の特徴は、出版社の商品説明に書かれている内容をもとにまとめています
- 表紙・価格・レビューは楽天ブックスの情報を毎週自動で更新しているので、古い年度版をすすめてしまうことを防いでいます

「この本を使って合格しました！」という個人の体験談ではありません。
「こういう勉強のしかたが合う人には、こういう作りの本が向いている」という、**選び方の地図**のつもりで作りました。
