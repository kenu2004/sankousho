## 3. 質問している人への返信テンプレート

X で「ITパスポート 参考書 どれ」「ITパス 参考書 おすすめ」などを検索すると、迷っている人の投稿が見つかる。

```
参考書選びで迷う人向けに、10問で勉強スタイルに合う本がわかる診断を作りました。よかったら参考にしてください（登録不要です）
https://kenu2004.github.io/sankousho/?utm_source=x&utm_medium=reply
※本のリンクは楽天アフィリエイトです（PR）
```

- 1日3件まで。同じ文をそのまま貼り続けると、スパム扱いされやすい
- 相手の質問（「初心者です」「時間がない」など）に一言ふれてから添える
- すでに答えが出ている投稿や、古い投稿には返信しない

## 4. 投稿の順番（例）

| 日 | 投稿 | 時間の目安 |
|---|---|---|
| 1日目 | プロフィールを整える → A1（固定）＋リンクのリプライ | 21〜22時 |
| 2日目 | B1 ＋リンクのリプライ | 7〜8時 または 21〜22時 |
| 3日目 | A2 | 21〜22時 |
| 4日目 | B3 ＋リンクのリプライ | 21〜22時 |
| 5日目 | A3 | 21〜22時 |
| 6日目 | B2 ＋リンクのリプライ | 7〜8時 |
| 毎日 | 質問している人への返信（1日3件まで） | いつでも |

1週間たったら、GA4 で次の数字を見て、効いた切り口を増やす。

- X から来た人数（参照元 `x`）
- `quiz_complete`（診断を最後までやった人）
- `click_book`（本のリンクを押した人）
